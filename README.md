# 🕯️ 나의 가능세계 | 가능세계 서재 (The Archive of Unchosen Paths)

> **"가보지 못한 길은 사라지지 않는다. 다만 우리가 뒤돌아보지 않는 시간 속에서 조용히 자라날 뿐이다."**

**나의 가능세계(가능세계 서재)**는 사용자의 기억과 성향, 간직한 사물, 그리고 미처 선택하지 못한 열망을 단서 삼아 **'지금의 내가 걸어갈 미래'**와 **'다른 선택을 했다면 존재했을 평행우주의 나'**의 조우를 그려내는 **AI 평행우주 단편소설 창작 웹 서비스**입니다.

## ✨ 주요 특징

* **심층 내면 설문 (6 Parts, 23 Questions):** 단순한 키워드 입력이 아닌, 삶의 변곡점·오래된 오브제·감정의 방어기제·선택하지 않은 길을 탐색하는 6단계 설문을 통해 인물의 입체적인 내면을 구축합니다.
* **문학적 서사 설계 및 굴절:** 설문 답변을 그대로 나열하지 않고, 현실의 단어를 문학적 비유와 감각적 묘사(시각·청각·후각·촉각)로 치환하여 밀도 높은 한국 현대 단편소설 문체로 집필합니다.
* **어두운 등불과 고서(古書) 테마 UI:** 등불이 켜진 고요한 서재의 분위기와 빛바랜 원고지 질감 속에서 실시간 타자기 효과로 소설이 집필되는 몰입형 경험을 제공합니다.
